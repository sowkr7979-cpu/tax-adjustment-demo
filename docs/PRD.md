# PRD: 법인세 세무조정 자동화 보조도구

## 목표
법인세 세무조정 용역에서 반복적으로 발생하는 자료 정리, 더존 엑셀 파싱, 계정별 검토, 주요 세무조정 항목 계산, 누락자료 요청, 감사추적 산출물 생성을 자동화한다.

이 도구의 목적은 최종 신고서를 AI가 확정하는 것이 아니다. 목적은 KICPA가 검토할 수 있는 세무조정 초안, 계산 근거, 검토 포인트, 누락자료 목록을 빠르게 만드는 것이다.

## 사용자
- KICPA 또는 세무조정 실무 담당자
- 더존 Smart A, WEHAGO, ERP 엑셀 자료를 받아 세무조정 검토를 수행하는 사람
- 고객자료를 외부 SaaS에 올리기 어렵고 로컬 PC에서 1차 검토를 하고 싶은 사람

## 핵심 기능
1. 회사 기본정보 입력 및 DART 회사정보 보조 조회 (최대주주·특수관계인 현황 자동입력 — 출처·지분율 표시)
2. 재무상태표, 손익계산서, 원가명세서, 고정자산대장, 분개장, 계정별원장 업로드
3. 일반 엑셀뿐 아니라 HTML형 `.xls` 파일 파싱
4. 분개장 기반 주요 세무조정 후보 추출
5. 접대비, 감가상각(정률법 비망가액 특례 포함), 지급이자, 기부금, 업무용승용차(차량별 근거분개) 등 규칙 기반 1차 계산
6. Ollama 기반 로컬 LLM 분석으로 검토 후보와 설명 초안 생성
7. 법령정보 API와 DART API를 이용한 근거 및 회사정보 보조 조회
8. 전수 검토 체크리스트 — 검토필요 항목에 근거법령·검토포인트(law.go.kr 검증)와 근거분개 첨부
9. 세무 컨설팅 코멘트 — 회사 숫자·세무조정 결과 기반 자문 토픽(시나리오)과 국세청 참고파일 근거(RAG)
10. 검토패키지 PDF, 감사추적 Excel 및 `.taxproj` 프로젝트 파일 출력

## MVP 범위
- 최종 신고서 전자신고 파일 생성은 MVP 범위가 아니다.
- AI가 세무판단을 확정하지 않는다.
- API 조회 실패 시 수기입력 또는 검토 필요로 표시한다.
- 고객자료는 원칙적으로 로컬 PC에서 처리한다.

## 실무상 필수 통제
- 당기순이익을 찾지 못하면 세액 계산을 계속하지 않는다.
- 파싱 실패와 미업로드를 구분해서 표시한다.
- 계산 결과에는 원천 파일, 시트, 행 번호 등 감사추적 정보를 남긴다.
- LLM 결과는 확정값이 아니라 검토 후보로 표시한다.
- 임시파일과 출력파일의 고객자료 잔존 위험을 관리한다.

## 성공 기준
- 더존 재무제표/분개장 샘플을 업로드했을 때 주요 자료가 파싱된다.
- 핵심 규칙/파서 테스트가 통과한다.
- 세무조정 계산 결과에 근거와 원천자료가 표시된다.
- 비개발자인 KICPA도 오류 메시지를 보고 다음 조치를 이해할 수 있다.
