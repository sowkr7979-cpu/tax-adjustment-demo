> **원칙**: 모든 서식 번호는 국가법령정보센터 API(`target=licbyl`) 조회 결과를 1차 출처로 한다.  
> 이 문서의 번호는 구현 착수 전 API로 재확인하며, 확인 완료 항목은 ✅, 미확인 항목은 ⚠️로 표시한다.  
> 코드에 서식 번호를 직접 하드코딩하지 말고, `FORM_REGISTRY` 상수 파일에서 관리한다.

## 1. 서식 번호 확인 절차

```python
# 구현 착수 전 실행하여 서식 번호·법령ID 확정
import requests

# search=2: 법령명 기준 검색 (기본값 search=1은 서식명만 검색 → 누락 발생)
params = {
    "OC": LAW_API_KEY,
    "target": "licbyl",
    "query": "법인세법 시행규칙",
    "search": 2,       # 법령명 기준 검색 (공식 API 가이드 lsBylListGuide 참조)
    "type": "JSON",
    "display": 200,    # 별지서식 수가 많으므로 충분히 크게
    "page": 1,
}
resp = requests.get("http://www.law.go.kr/DRF/lawSearch.do", params=params)
# → bylList[].bylNm(서식명), bylList[].bylSeq(법령ID) 추출
# → bylList[].bylNo(서식번호), bylList[].bylGbn(서식구분) 확인
# → 이 문서의 서식 번호와 대조 후 확정
# → 페이지 수(totalCnt) 확인 후 page=2,3 추가 조회 필요 시 반복
```

## 3. 서식별 금액 매핑 테이블

각 세무조정 계산 결과가 서식의 어느 란에 들어가는지 정의한다.  
란 번호는 서식 파일 다운로드 후 확인·확정한다.

### 3-1. 기업업무추진비 조정명세서 (제16호서식 갑) ⚠️

```
계산 결과            → 서식 란
───────────────────────────────────────────────────────
기업업무추진비 합계  → ① 지출한 기업업무추진비 합계액
  - 법인카드 분      → ② 신용카드 사용액
  - 기타 증빙 분     → ③ 기타 증빙액
수입금액 기준 한도   → ⑥ 수입금액별 한도액
기본 한도            → ⑤ 기본 한도액 (중소기업 3,600만원)
문화비 한도          → ⑦ 문화비 추가 한도
총 한도              → ⑧ 한도액 합계
한도초과액           → ⑨ 한도초과액 (손금불산입)
  → 소득금액조정합계표 손금불산입 행
  → 법인세 과세표준 및 세액신고서 소득금액 조정란
```

### 3-2. 감가상각비 조정명세서 (제20호서식) ⚠️

```
계산 결과                → 서식 란
────────────────────────────────────────────────────────────
자산별 세무상 상각범위액 → ① 세무상 상각범위액
회사 계상 상각비         → ② 회사 계상 상각비
한도초과액 (②-①)        → ③ 한도초과액 (손금불산입)
전기 부인누계액          → ④ 전기말 부인누계액
당기 시인액              → ⑤ 당기 시인액 (손금산입)
당기말 부인누계액        → ⑥ 당기말 부인누계액
  → 자본금과 적립금 조정명세서(을) 감가상각 유보 항목
```

### 3-3. 자본금과 적립금 조정명세서 갑/을 (제50호서식) ✅

```
계산 결과              → 서식 란
────────────────────────────────────────────────────
(갑) 이익잉여금 내역   → 당기순이익, 배당, 이월
(을) 유보 항목별 잔액  → 전기이월 + 당기증감 = 기말잔액
  - 감가상각 부인누계  → 해당 행
  - 기부금 한도초과    → 해당 행
  - 대손충당금 한도초과 → 해당 행
  - 퇴직급여충당금     → 해당 행
  ※ 당기 세무조정 결과가 자동으로 이 표에 반영되어야 함
```

### 3-4. 최저한세 조정계산서 (제4호서식) ⚠️

```
계산 결과                → 서식 란
────────────────────────────────────────────────────────
산출세액                 → ① 산출세액
세액공제·감면 전 세액     → ② 최저한세 적용 전 세액
최저한세율 적용세액       → ③ 최저한세액 (중소기업: 과세표준 × 7%)
  조정 감면세액           → ④ 최저한세 초과로 배제되는 감면세액
최종 납부세액 계산        → ⑤ 조정 후 세액
```

## 4. 소득금액조정합계표 연결 구조

모든 세무조정 항목은 최종적으로 소득금액조정합계표에 집계된다.

```
손금불산입 항목         → 소득금액조정합계표 [손금불산입] 섹션
  - 감가상각비 한도초과
  - 기업업무추진비 한도초과
  - 기부금 한도초과
  - 퇴직급여충당금 한도초과
  - 대손충당금 한도초과
  - 지급이자 손금불산입
  - 업무용승용차 한도초과
  - 벌과금·과태료
  - 임원 상여금 한도초과

익금산입 항목           → 소득금액조정합계표 [익금산입] 섹션
  - 가지급금 인정이자
  - 채무면제익
  - 자산수증익

손금산입 항목           → 소득금액조정합계표 [손금산입] 섹션
  - 감가상각비 시인액 (전기 부인액 환입)

익금불산입 항목         → 소득금액조정합계표 [익금불산입] 섹션
  - 수입배당금 익금불산입

합계                    → 법인세 과세표준 및 세액신고서 소득금액 조정란
```

## 5. 세율 테이블 (사업연도 개시일 기준)

> **구현 원칙**: 신고연도가 아니라 **사업연도 개시일** 기준으로 세율 테이블을 선택한다.

```python
def get_tax_rate_table(fiscal_year_start: date) -> list[tuple]:
    """
    사업연도 개시일 기준 세율 테이블 반환.
    각 tuple: (과세표준_하한, 과세표준_상한, 세율, 누진공제액)
    """
    if fiscal_year_start < date(2026, 1, 1):
        # 2025년 개시 사업연도 (2026년 신고 포함)
        return [
            (0,          200_000_000,   0.09, 0),
            (200_000_000, 20_000_000_000, 0.19, 20_000_000),
            (20_000_000_000, 300_000_000_000, 0.21, 420_000_000),
            (300_000_000_000, None,           0.24, 9_420_000_000),
        ]
    else:
        # 2026년 이후 개시 사업연도 (1%p 인상)
        return [
            (0,          200_000_000,   0.10, 0),
            (200_000_000, 20_000_000_000, 0.20, 20_000_000),
            (20_000_000_000, 300_000_000_000, 0.22, 420_000_000),
            (300_000_000_000, None,           0.25, 9_420_000_000),
        ]
```
