# 규칙 엔진 세무조정 계산 설계

> **원칙**: 모든 금액 계산은 이 규칙 엔진이 담당한다. LLM은 세무조정 후보를 발굴·분류할 뿐이며,  
> 손금불산입액 확정·한도 계산·세액 산출은 절대 LLM에 맡기지 않는다.

## 2. 손금불산입 계산 모듈

### 2-1. 기업업무추진비 (`entertainment.py`)

**근거**: 법인세법 제25조 (law.go.kr 원문 확인 — 2025-12-31 시행)

```python
def calc_entertainment(
    total_expense: int,       # 기업업무추진비 합계 (증빙불비 포함)
    card_expense: int,        # 법인카드·신용카드 지출액
    culture_expense: int,     # 문화비 (공연·도서 등)
    traditional_expense: int, # 전통시장 지출액
    no_receipt_expense: int,  # 증빙불비 (건당 3만원 초과·적격증빙 미수취 → 전액 불산입, 법§25②)
    revenue: int,             # 수입금액 합계
    is_sme: bool,             # 중소기업 여부
    is_specified_corp: bool,  # 특정법인 (영§42② 3요건) — 한도 ×50% (법§25⑤)
    months: int,              # 사업연도 월수 — 기본한도 월수/12 안분 (법§25④1호)
) -> EntertainmentResult:
    기본한도 = (36_000_000 if is_sme else 12_000_000) * months // 12

    # 수입금액 구간별 적용률 (법§25④2호)
    if revenue <= 10_000_000_000:
        수입금액한도 = int(revenue * 0.003)
    elif revenue <= 50_000_000_000:
        수입금액한도 = 30_000_000 + int((revenue - 10_000_000_000) * 0.002)
    else:
        수입금액한도 = 110_000_000 + int((revenue - 50_000_000_000) * 0.0003)

    # 특수관계인 매출 (법§25④2호 단서): 적용률 산출액의 10%만 인정
    # — 매출 분개 거래처를 1단계 특수관계인 목록과 자동 대조 (sum_related_party_revenue)
    # 한도 = f(일반수입금액) + [f(전체수입금액) − f(일반수입금액)] × 10%

    base_rev = 기본한도 + 수입금액한도
    if is_specified_corp:
        base_rev //= 2        # 법§25⑤ — 특정법인은 ④ 각 호 합계의 50%

    문화비한도 = min(culture_expense, base_rev)
    전통시장한도 = min(traditional_expense, base_rev)
    총한도 = base_rev + 문화비한도 + 전통시장한도

    한도초과액 = max(0, (total_expense - no_receipt_expense) - 총한도)
```

> 증빙불비 기준: 건당 **3만원** 초과 + 적격증빙(카드·세금계산서·계산서·현금영수증) 미수취 (법§25②).
> **카드번호가 기재된 분개는 증빙유형 칸이 비어도 카드거래로 인정** (증빙불비 아님).
> 분개장에 증빙 정보가 아예 없으면(WEHAGO 등) 판정을 건너뛰고 "판정 불가" 표시.

### 2-2. 감가상각비 (`depreciation.py`)

**근거**: 법인세법 제23조, 법인세법 시행령 제26~28조

```python
def calc_depreciation_per_asset(asset: FixedAsset) -> dict:
    """
    자산별 세무상 상각범위액 계산.
    반환: {
        "세무상_상각범위액": int,
        "회사_계상액": int,
        "한도초과액": int,   ← 손금불산입
        "시인액": int,       ← 당기 시인 (전기 부인 환입 포함)
        "당기말_부인누계": int,
    }
    """
    if asset.method == "정률법":
        상각범위액 = int(asset.전기말_장부가액 * asset.상각률 * asset.월수 / 12)
    elif asset.method == "정액법":
        상각범위액 = int(asset.취득가액 / asset.내용연수 * asset.월수 / 12)
    ...
    한도초과액 = max(0, asset.회사계상_상각비 - 상각범위액)
    시인액 = min(asset.전기_부인누계액, max(0, 상각범위액 - asset.회사계상_상각비))
    return {...}
```

### 2-4. 충당금 (`allowances.py`)

**근거**: 법인세법 제33조(퇴직급여충당금), 제34조(대손충당금)

```python
def calc_retirement_allowance(
    period_end_estimate: int,   # 기말 퇴직급여 추계액
    pension_asset: int,         # 퇴직연금 운용자산
    current_balance: int,       # 회사 계상 충당금 잔액
) -> dict:
    """퇴직급여충당금: 한도 = 0% (현행) → 전액 한도초과 = 전액 손금불산입"""
    한도 = 0  # 법령§60 현행: 0%
    한도초과 = max(0, current_balance - 한도)
    return {"한도초과액": 한도초과}

def calc_bad_debt_allowance(
    receivable_balance: int,    # 채권 잔액 합계
    actual_bad_debt_rate: float,  # 직전 3년 대손실적률
    current_balance: int,       # 회사 계상 충당금
) -> dict:
    """대손충당금: 한도 = 채권잔액 × max(1%, 대손실적률)"""
    rate = max(0.01, actual_bad_debt_rate)
    한도 = int(receivable_balance * rate)
    한도초과 = max(0, current_balance - 한도)
    return {"한도": 한도, "한도초과액": 한도초과}
```

### 2-5. 지급이자 손금불산입 (`interest.py`)

**근거**: 법인세법 제28조, 시행령 제49·53조 (law.go.kr 원문 확인)

```python
# 데이터 흐름 (구현 기준):
#   이자비용 총액  ← 분개장 자동 집계 (aggregator.interest_expense)
#   1호·3호       ← 3단계 '이자비용 전체 표'에서 라인별 체크박스 분류
#   업무무관자산   ← 3단계 계정별 명세 체크 (회원권·콘도 등, 가목·영§49)
#   가지급금 적수  ← 3단계 분개 체크 → 상대방별 일별 적수, 가수금 상계 (나목·영§53①③)
#   차입금 적수    ← B/S 기초잔액 + 분개장 당기 증감 일별 계산 (영§53③)

1호 채권자불분명 = 체크 라인 전액 손금불산입 (대표자상여 등)
2호 비실명 채권·증권이자 = 체크 라인 전액 손금불산입 (소득세법§16①1·2·5·8호 중 지급받은 자 불분명, 대표자상여 등)
3호 건설자금이자 = 체크 라인 전액 자본화 (유보)

# 4호 (영§53②③ — '적수' 기준, 전 항목 B/S 기초잔액 + 분개장 당기 증감 일별 계산):
기준이자 = max(0, 이자비용총액 − 1호 − 2호 − 3호)
업무무관자산적수 = Σ 체크 계정별 account_jeoksu(기초잔액 + 분개 증감)   # 폴백: 기말×일수
분자적수 = 업무무관자산적수 + 가지급금 적수(상대방별 합계, 가수금 상계 후)
비율     = min(1, 분자적수 ÷ 차입금적수)        # 한도: 차입금 적수
불산입_업무무관 = int(기준이자 × 비율)            # 기타사외유출
# 계산 내역에 계정별 적수 산정 방식(일별 계산/근사)을 표기
```

> ⚠ 구버전 설계의 분모 '총자산'은 법령과 다름 — 영§53②의 분모는 **차입금 적수**.
> 가지급금 인정이자(법§52)와 4호 업무무관이자(법§28)는 **별개 조정으로 동시 적용**된다.

## 3. 익금산입 계산 모듈 (`income_items.py`)

**근거**: 법인세법 시행령 제89조(인정이자), **조세특례제한법 제138조·동 시행령 제132조(간주임대료)**
(law.go.kr 원문 확인 — 2025-12-31 시행)

```python
PRIME_RATE = 0.046  # 당좌대출이자율 — 매년 국세청 고시값으로 갱신

def calc_deemed_interest_by_party(
    parties: list[tuple[str, int, int]],   # [(거래상대방, 가지급금 적수, 약정이자)]
    rate: float,    # 가중평균차입이자율 (영§89③ 원칙) — 미입력 시 당좌대출이자율
    days: int,      # 사업연도 일수
) -> DeemedInterestByPartyResult:
    """가지급금 인정이자 — '거래상대방별' 계산 (별지 제19호 구조).

    law.go.kr 원문 확인:
      영§89⑤: 시가와의 차액 익금산입 / 영§89③: 시가 = 가중평균차입이자율 원칙
      영§88③: 6호(금전대여)는 차액 ≥ 3억원 또는 시가의 5% 이상인 경우에 한해 적용
      영§53③: 동일인 가수금은 상계 (적수 단계에서 일별 반영)

    상대방별: 인정이자 = 적수 × 이자율 ÷ 365 − 약정이자(이자수익 분개 자동 매칭)
    상대방 간 통산 없음 — 한 상대방의 초과 약정이자가 다른 상대방과 상계되지 않는다.
    적수는 jeoksu.py가 3단계에서 체크된 가지급금·대여금 분개의 거래 날짜로 일별 계산.
    기초 이월 가지급금은 B/S 가지급금·대여금 '기초잔액'에서 자동 prefill (수정 가능,
    상대방 미지정분은 별도 행으로 적수 = 기초잔액 × 사업연도일수).
    """

def calc_deemed_rental(
    deposit: int,             # 임대보증금 등 (기말잔액 — 적수 폴백용)
    debt: int,                # 차입금 잔액
    equity: int,              # 자기자본 = max(자산-부채, 납입자본금) (조특령§132①)
    bank_rate: float,         # 정기예금이자율
    is_rental_main: bool,     # 부동산임대업 주업 — 자산총액 중 임대자산 50% 이상 (조특령§132③)
    construction_cost: int,   # 임대용부동산 건설비상당액 (토지 제외, 조특령§132⑥)
    financial_income: int,    # 보증금 운용 금융수익 — 이자·할인료·배당 (조특령§132⑤)
    deposit_jeoksu: int,      # 보증금 적수 — B/S 기초잔액 + 분개장 당기 증감 일별 계산
    debt_jeoksu: int,         # 차입금 적수 — B/S 기초잔액 + 당기 증감 일별 계산
    construction_jeoksu: int, # 건설비상당액 적수 — 건물·구축물 분개 일별 × 임대용 비율
                              #   (임대용 비율 = 입력 건설비 ÷ 기말 건물가액, 건설비는 자동 prefill)
    days: int,                # 사업연도 일수
) -> DeemedRentalResult:
    """임대보증금 등의 간주익금 (조특법§138) — 적수(積數) 기준.

    적용 요건 (둘 다 충족해야 적용):
      1. 부동산임대업 주업 (1단계 기본정보에서 판정)
      2. 차입금 '적수' > 자기자본 '적수' × 2 (조특령§132① — 자기자본은 기말×일수 근사)

    산식 (조특령§132⑤):
      익금가산 = (보증금 적수 − 건설비상당액 적수) × 1/365 × 정기예금이자율 − 금융수익
      음수이면 0. "적수의 계산은 매월말 현재의 잔액에 경과일수를 곱하여 계산할 수 있다"
    ⚠ 구버전 설계의 '과다차입금을 보증금 상한으로 쓰는 방식'은 법령에 없는 산식 — 폐기.
    """
```

### 부당행위계산 부인 (법§52, 영§88·89⑤) — 수기 산정 + 자동 참고

- 금전 대여(영§88①6호)는 위 인정이자에서 **자동 계산** — 중복 입력 금지
- 고가매입·저가양도 등은 시가(감정가액·상증법 평가) 비교가 필요해 **수기 입력**
  (`unfair_transaction_amount`) — 3단계에서 특수관계인 거래 분개 참고 표 자동 제공
- 적용 기준 (영§88③): 시가와 거래가액의 차액 ≥ 3억원 또는 시가의 5% 이상
  (상장주식 거래는 제외 — 영§88④)
- 익금산입, 소득처분은 귀속자에 따라 배당·상여·기타사외유출

## 4. 과세표준 및 세액 계산 (`tax_base.py`)

```python
def calc_taxable_income(
    net_income: int,              # 당기순손익
    add_back: int,                # 손금불산입 + 익금산입 합계
    deduct: int,                  # 손금산입 + 익금불산입 합계
) -> int:
    return net_income + add_back - deduct

def calc_tax_base(
    business_income: int,         # 각 사업연도 소득금액
    carryforward_loss: int,       # 공제 가능 이월결손금
    is_sme: bool,
    non_taxable: int = 0,
    income_deduction: int = 0,
) -> int:
    """이월결손금: 중소기업 100% 공제, 일반 80% 한도"""
    loss_deduction_limit = carryforward_loss if is_sme else int(business_income * 0.8)
    loss_deduction = min(carryforward_loss, loss_deduction_limit)
    return max(0, business_income - loss_deduction - non_taxable - income_deduction)

def calc_tax(
    tax_base: int,
    fiscal_year_start: date,
) -> int:
    """산출세액 = 과세표준 × 세율 - 누진공제"""
    table = get_tax_rate_table(fiscal_year_start)  # 별지서식_금액매핑_설계.md 참조
    for lower, upper, rate, deduction in table:
        if upper is None or tax_base <= upper:
            return int(tax_base * rate) - deduction
    return 0
```

## 5. 세액공제·감면 및 최저한세 (`tax_credit.py`)

**근거**: 조세특례제한법 제132조(최저한세)

```python
MIN_TAX_RATE_SME = 0.07  # 중소기업 7% (조특§132①)

def get_min_tax_rate(tax_base: int, is_sme: bool) -> float:
    """
    일반법인 최저한세율 (조특§132①) — 과세표준 구간별 세율.
    중소기업은 항상 7%.
    """
    if is_sme:
        return 0.07
    # 일반법인 구간별 세율 (2025년 기준)
    if tax_base <= 10_000_000_000:        # 100억 이하
        return 0.10
    elif tax_base <= 100_000_000_000:     # 1,000억 이하
        return 0.12
    else:                                  # 1,000억 초과
        return 0.17

@dataclass
class TaxCredit:
    name: str
    amount: int
    subject_to_min_tax: bool  # True: 최저한세 적용 대상 감면, False: 최저한세 후 공제

def calc_final_tax(
    gross_tax: int,               # 산출세액
    tax_credits: list[TaxCredit], # 세액공제·감면 항목별 목록 (적용대상 구분 포함)
    tax_base: int,
    is_sme: bool,
    surtax: int = 0,              # 가산세
    prepaid_tax: int = 0,         # 중간예납·원천징수 기납부세액
) -> dict:
    """
    최저한세 적용 순서:
    1. 산출세액 - 최저한세 적용 대상 감면·공제 = 감면 후 세액
    2. 감면 후 세액 < 최저한세액 → 초과분 감면 배제
    3. 최저한세 이후 공제(최저한세 미적용 감면) 추가 차감
    4. 가산세 가산, 기납부세액 차감
    """
    min_tax_credits = sum(c.amount for c in tax_credits if c.subject_to_min_tax)
    post_min_tax_credits = sum(c.amount for c in tax_credits if not c.subject_to_min_tax)

    # 최저한세 적용 대상 감면 반영
    after_credit = max(0, gross_tax - min_tax_credits)

    # 최저한세 계산
    min_rate = get_min_tax_rate(tax_base, is_sme)
    최저한세액 = int(tax_base * min_rate)

    if after_credit < 최저한세액:
        배제감면 = 최저한세액 - after_credit
        세액_after_min = 최저한세액
    else:
        배제감면 = 0
        세액_after_min = after_credit

    # 최저한세 미적용 감면 추가 차감
    최종_세액 = max(0, 세액_after_min - post_min_tax_credits)

    차감납부세액 = max(0, 최종_세액 + surtax - prepaid_tax)
    return {
        "산출세액": gross_tax,
        "최저한세_적용_감면합계": min_tax_credits,
        "최저한세_미적용_감면합계": post_min_tax_credits,
        "최저한세율": min_rate,
        "최저한세액": 최저한세액,
        "배제된_감면": 배제감면,
        "최종_세액": 최종_세액,
        "가산세": surtax,
        "기납부세액": prepaid_tax,
        "차감납부세액": 차감납부세액,
        "농어촌특별세": farm_surtax,   # 아래 5-1 참조
    }
```

> **입력 연결 (구현):** `TaxCredit` 목록·`surtax`·`prepaid_tax`는 3단계 수기 입력
> (`ManualInput.tax_credit_items` = `[{name, amount, subject_to_min_tax, farm_surtax_taxable}]`,
> `surtax_amount`, `prepaid_tax_amount`)에서 받아 `views/calc.py`의 `compute_all(...)`에 전달한다.
> (과거 `tax_credits=[]` 하드코딩으로 세액공제가 계산에 반영되지 않던 문제를 해소 — Critical#1)

### 5-1. 농어촌특별세 (`tax_credit.py`)

**근거**: 농어촌특별세법 제5조①(과세표준·세율), 제4조(비과세) — law.go.kr 법령ID **001569** 원문 확인.

```python
FARM_SURTAX_RATE = 0.20  # 조특법 감면세액분 (농특세법§5① 1호)

# 농특세 = (농특세 과세대상 감면세액 − 최저한세로 배제된 감면) × 20%
farm_taxable = sum(c.amount for c in tax_credits if c.farm_surtax_taxable)
farm_surtax = int(max(0, farm_taxable - 배제감면) * FARM_SURTAX_RATE)
```

- **과세대상**: 통합투자세액공제(조특§24) 등. 감면별 `farm_surtax_taxable` 플래그로 지정.
- **비과세(농특세법§4)**: 조특§6·§7 중소기업 세액감면·특별세액감면, R&D세액공제 등 → 플래그 해제.
- 최저한세로 **배제된 감면은 실제 감면받지 못하므로 농특세 과세표준에서 제외**.
- 농특세는 법인세와 **별도 신고·납부**이므로 차감납부세액에 포함하지 않고 별도 표시.

### 5-2. 가산세 (`penalty_surtax.py`)

**근거**: 국세기본법 제47조의2~4 — law.go.kr 법령ID **001586** 원문 확인.

- **무신고**(§47의2): 무신고납부세액 × 20%(부정 40%·역외부정 60%). 법인은 `수입금액×0.07%(부정 0.14%)`와 비교해 큰 금액.
- **과소신고**(§47의3): 부정분 × 40%(역외 60%) + 일반분 × 10%.
- **납부지연**(§47의4): 미납세액 × 미납일수 × **1일 22/100,000**(국기령, 2022.2.15~).
- 지급명세서·계산서 등 **법§75 계열**은 요율이 다양해 자동 산정 대상에서 제외 — `other_manual` 수기 합산.
- `aggregate_surtax(...)` → `SurtaxResult` → 5단계에서 `surtax`로 `compute_all`에 전달(계산기 UI 제공).

### 5-3. 세액공제·감면 카탈로그 (`tax_credit_catalog.py`)

변동이 잦은 **공제율·감면율은 파라미터**로 받고(엔진은 산식 구조만), 안정적인
**최저한세 적용 여부(조특§132)·농특세 과세 여부(농특세법§4)는 카탈로그로 자동판정**한다.
- `calc_sme_special_reduction`(조특§7), `calc_rnd_credit`(조특§10), `calc_integrated_investment_credit`(조특§24).
- `lookup_credit_spec(name)` → 항목명으로 최저한세·농특세 분류 추천(3단계 UI 표시), 회계사 확정.

> **남은 단순화(설계 의도):** 조특 감면·공제의 **공제율·감면율 별표**(업종·지역·규모·연도별, 매년 개정)는
> 하드코딩하지 않고 현행값을 입력받는다 — 율표 자동화는 별표 데이터 정비 후 별도 과제.
> 법§55의2(토지등 양도소득)·법§18 4·5호·가산세 핵심 3종은 구현 완료.

## 6. 계산 순서 (의존성 그래프)

```
[입력: Smart A 재무자료 + 수기 입력]
         ↓
[1] 감가상각비 한도 계산 (depreciation.py)
     → 한도초과액 → 손금불산입 Pool
     → 시인액 → 손금산입 Pool
     → 당기말 부인누계액 → 자본금·적립금(을) 반영
         ↓
[2] 기업업무추진비 한도 계산 (entertainment.py)
     → 한도초과액 + 증빙불비 → 손금불산입 Pool
         ↓
[3] 기부금 한도 계산 (donation.py)
     ※ 기준소득이 필요하므로 [1][2] 완료 후 계산
     → 초과액 → 손금불산입 Pool (이월공제 표시)
         ↓
[4] 충당금 한도 계산 (allowances.py)
     → 한도초과 → 손금불산입 Pool
         ↓
[5] 지급이자 손금불산입 (interest.py)
     → 업무무관이자 + 채권자불분명 → 손금불산입 Pool
         ↓
[6] 익금산입 계산 (income_items.py)
     → 인정이자 + 간주임대료 + 기타 → 익금산입 Pool
         ↓
[7] 기타 (other_adjustments.py, vehicle.py, dividend.py, forex.py)
     → 각 Pool 반영
         ↓
[8] 소득금액 조정합계 계산 (tax_base.py)
     = 당기순이익 + 손금불산입·익금산입 - 손금산입·익금불산입
         ↓
[9] 과세표준 계산 (tax_base.py)
     - 이월결손금 공제
     = 과세표준
         ↓
[10] 산출세액 계산 (tax_base.py)
     × 세율 테이블 (사업연도 개시일 기준)
         ↓
[11] 세액공제·감면 + 최저한세 + 차감납부세액 (tax_credit.py)
         ↓
[출력: 세무조정 결과 → 서식 매핑 → 신고서 Excel]
```

## 8. 단위 테스트 기준

각 계산 함수는 다음 케이스를 포함한 단위 테스트를 갖춰야 한다.

| 모듈 | 필수 테스트 케이스 |
|------|-----------------|
| `entertainment.py` | 중소기업/일반법인, 문화비 추가한도, 증빙불비 혼합 |
| `depreciation.py` | 정률법·정액법, 기중 취득(월할), 의제상각, 전기 부인누계 환입 |
| `donation.py` | 특례·일반·비지정 혼합, 이월공제 처리 |
| `allowances.py` | 대손실적률 1% 미만, 퇴직연금 운용자산 공제 |
| `tax_base.py` | 이월결손금 100%/80% 한도, 각 세율 구간 경계값 |
| `tax_credit.py` | 최저한세 초과 감면배제, 중간예납 공제 |
