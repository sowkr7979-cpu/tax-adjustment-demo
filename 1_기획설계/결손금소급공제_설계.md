# 중소기업 결손금 소급공제 환급 — 설계안 (리뷰용 초안)

## 1. 목적
중소기업이 당기 결손 발생 시 직전 사업연도 법인세를 환급받는 **결손금 소급공제(법§72)**
검토를 보조한다. 환급 신청 여부는 회계사·납세자가 확정하고, 앱은 **환급가능세액 초안·근거·검토포인트**를 제시한다.

## 2. 법령 근거 (law.go.kr 확인 완료, efYd 2025-12-31)
- **법인세법 §72** (001563 / JO 007200) — 중소기업의 결손금 소급공제에 따른 환급
  - ① 직전 사업연도 법인세액 한도, [1호 − 2호] 환급 신청 가능
    - 1호: 직전 산출세액 (§55의2 토지등양도소득 법인세 제외)
    - 2호: (직전 과세표준 − 소급공제 결손금 상당액) × 직전 §55① 세율
  - ② 신고기한(§60)까지 신청 / ④ **직전·당기 모두 기한내 신고한 경우에만 적용**
  - ⑤ 추징 사유 + 이자상당액
- **법인세법 시행령 §110** (003608 / JO 011000)
  - ① "직전 사업연도 법인세액"(=한도) = 직전 산출세액(토지등양도 제외) − 직전 공제·감면세액
  - ② 별지 **소급공제법인세액환급신청서** 신고기한 내 제출
  - ④ 이자상당액 = 환급세액 × 1일 22/100,000 (추징 시)
  - ⑤ 소급공제 결손금 > 직전 과세표준이면 초과분은 소급공제 결손금으로 보지 않음

## 3. 산식
```
환급가능세액 = min(
  ① 직전 산출세액(토지등양도 제외) − calc_gross_tax(직전 과세표준 − 소급공제결손금, 직전 사업연도 개시일),
  ② 한도 = 직전 산출세액(토지등양도 제외) − 직전 공제·감면세액
)
제약: 소급공제결손금 ≤ min(당기 결손금, 직전 과세표준)   (영§110⑤)
```
- **직전 세율 적용이 핵심** — `calc_gross_tax`에 *직전* 사업연도 개시일을 넘겨 직전연도 세율테이블로 2호를 계산
  (당기 세율 아님 — 세율 개정 이력 대응). 기존 `tax_base.calc_gross_tax` 재사용.

## 4. 입력 데이터 (수기입력 + 규칙엔진 하이브리드)
| 항목 | 출처 | 비고 |
|---|---|---|
| 당기 결손금 | **규칙엔진** | 각사업연도소득 < 0 — 기존 계산 결과 재사용 |
| 직전 과세표준 | 수기입력 / 전년 `.taxproj` 승계 | |
| 직전 산출세액 | 수기입력 / 승계 | §55의2 토지등양도 제외분 |
| 직전 공제·감면세액 | 수기입력 / 승계 | 한도 계산용 |
| 직전·당기 기한내 신고 여부 | 회계사 체크박스 | 법§72④ 요건 게이트 |
| 소급공제 신청 결손금액 | 회계사 입력 (한도 내 기본 제시) | 납세자 선택 — 전액/일부 |
| 중소기업 여부 | `sme_checker` 재사용 | 법§72① 요건 |

→ **순수 수기입력 아님**: 입력 4개 직전연도 값은 수기/승계, 계산은 규칙엔진 전용(ADR-002 준수).

## 5. 구현 위치
- `src/rules/loss_carryback.py` (신규) — `compute_loss_carryback(...) -> 결과 dataclass`. 순수 함수.
- `src/project/taxproj.py ManualInput` — 직전연도 4필드 + 신고요건 플래그 + 소급공제신청결손금 추가.
  `carry_forward_from`에 직전 산출세액·과세표준·공제감면 승계 추가.
- `src/ui/manual_input.py` — 직전연도 입력 expander (중소기업·당기결손 시에만 노출).
- `src/views/calc.py` — 세액 단계에 환급가능세액 카드 + 5단계 드릴다운(산식·사유·법§72·영§110).
- `src/rules/legal_basis.py` — 법§72·영§110 매핑 등록.
- 별지 출력: **별지68호 REFUND_REQUEST 이미 registry 등록(verified=True)** — summary_rows/registry 연결.

## 6. 검토포인트 (LLM/coverage 서술, 계산 아님)
- 추징 리스크(법§72⑤): 당기 결손 경정 감소·직전 경정·중소기업 탈락 시 이자상당액(1일 22/100,000) 추징.
- 소급공제 vs 이월공제(법§13①1호) **선택 의사결정** — 앱은 양쪽 효과만 제시, 확정은 회계사.
- 직전 사업연도가 흑자·법인세 납부했는지 전제 확인.

## 7. 처리 안 하는 것 (범위 밖)
- 추징세액 실제 계산(사후 경정 시점 별건) — 검토포인트 안내까지만.
- 환급신청서 자동 전자제출 — 별지 출력까지만.

## 8. kicpa-design-reviewer 리뷰 반영 (2026-06-10)
- **[🔴-1 직전 세율테이블]** `_RATE_TABLES`는 2023·2026만 수록. law API efYd 시점조회가
  세율 **표(각 호)**에는 미적용(2022 조회에도 현행 반환) → 과거 세율 임의 하드코딩 금지.
  → **결정:** 2호는 `calc_gross_tax(직전 개시일)`로 계산하되, **직전 개시일 < 2023-01-01이면
  경고 + 회계사가 2호 금액을 직접 입력/오버라이드**. (직전 ≥ 2023은 엔진 자동 — 현실 대다수.)
- **[🔴-2 한도·가산세]** 한도(②)의 "직전 법인세액"은 **산출세액 기준, 가산세 제외**(영§110①).
  입력표에 가산세 미포함 명시. 기납부세액은 환급 한도와 무관(한도는 산출세액−공제감면).
- **[⚠️-1 당기 결손금]** `당기 결손금 = max(0, −result.business_income)` 명문화
  (각사업연도결손금 기준, 과세표준 음수 아님). `compute_all` 후 추출.
- **[⚠️-2 별지68호 row]** registry 등록만 있고 row 빌더 부재 → 별지68호 전용 row 빌더 신설
  (직전 ①과표·②산출세액·③공제감면, 환급가능세액, 신청 결손금). 별지15호 구조와 분리.
- **[⚠️-3 드릴다운]** 환급가능세액은 **별지15호·소득처분과 무관한 독립 카드**(`final_tax_due` 확정 이후).
- **[⚠️-4 검토패키지]** review_pdf에 "결손금 소급공제 검토" 섹션 추가(산식·직전값 출처·검토포인트).
- **[⚠️-5 추징 안내]** 법§72⑤ 추징·이자(1일 22/100,000)를 **coverage _GUIDANCE 고정 항목**으로 등록
  (LLM 가변 서술 의존 금지).
- **[❓ 결정]**
  - 농특세 연계: v1 범위 밖, 검토포인트로만 안내 (law-compliance 확인).
  - 직전 0원 게이트: 직전 산출세액 ≤ 0 또는 직전 법인세액(한도) ≤ 0이면 환급 0 → 카드 미노출.
  - 중소기업 판정: **당기(결손 발생연도) `company.is_sme`** 기준 (법§72① 당기 요건).
  - 차기 이월결손금 차감: 소급공제 신청 결손금은 **차기 승계 이월결손금에서 제외**
    (`carry_forward_from` 보강 — 내년 이월결손금 과대 승계 방지).
